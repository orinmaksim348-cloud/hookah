## ✨ Особенности и функционал сайта

- **Taste-Skill & Motion Design:** Эстетичная темная цветовая гамма (уголь, глубокий индиго, теплый янтарный акцент), выверенная микро-анимация.
- **Интерактивные зоны и атмосфера:** Табы переключения залов (PlayStation 5, Большие экраны для трансляций, Уютные ложи, Чайный бар).
- **Живой статус работы:** Автоматический расчет статуса заведения («Открыто до ...» / «Откроется в 18:00») по часовому поясу Шахт (MSK).
- **Боковое информационное меню (Side Drawer):** Компактный доступ ко всем деталям (правила 18+, кухня, парковка, Wi-Fi, способы оплаты).
- **Модальное окно бронирования:** Быстрая форма брони стола с выбором даты, времени и зоны.
- **Интерактивная карта Яндекс:** Встроенная метка заведения на ул. Советская, 188А.
- **Полная адаптивность:** От смартфонов до 4K-дисплеев.

## 🚀 Запуск и деплой

Сайт полностью статичен и не требует сборки.

### Локальный просмотр:
1. Откройте `index.html` в любом современном браузере.
2. Или запустите локальный сервер:
   ```bash
   npx serve .
   # или
   python -m http.server 8000
   ```
